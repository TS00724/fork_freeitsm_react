## Original versus new work

Vite, or frontend test. WP-02 adds the isolated foundation; no earlier scaffold
was overwritten.

## Implemented

- React 18 / strict TypeScript / EUI Borealis / Vite / React Router manifest;
- runtime `BASE_URL`, app path, locale, timezone, and color-mode configuration;
- provider order for runtime config, theme, extension points, unresolved auth,
  unresolved tenant, unresolved permission, and BrowserRouter;
- minimal AppShell and architecture-review-only navigation;
- Error Boundary plus 403, 404, and generic error skeletons;
- light/dark toggle;
- API transport placeholder with same-origin credentials and optional CSRF hook,
  but no endpoint or response contract;
- empty feature convention and unit/component test skeletons;
- isolated `frontend/dist/` output and local verification scripts;
- code-reading guide, architecture diagram, and third-party review.
