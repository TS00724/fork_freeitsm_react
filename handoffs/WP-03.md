## User-approved G1 decisions

1. React mounts under `${BASE_URL}ui/`.
2. Apache remains the current server target; Nginx stays a future-compatible deployment option.
3. React AppShell follows the PHP information architecture but maps responsibilities to EUI patterns. PHP and React remain in parallel.
4. Initial theme is Light.
5. Future browser auth continues with PHP Session; 401/403 semantics and layered CSRF direction are documented, not implemented.
6. Future SOC identity is level-1; FreeITSM identity/tenant/role/capability is level-2 behind an adapter/context boundary.
7. Minimum React locales: English, Simplified Chinese, Traditional Chinese; timezone separately configurable.
8. API type strategy: generated transport DTO/enums plus handwritten frontend models.
9. Calendar remains the recommended first post-security vertical slice, Watchtower next and Tickets later; final pilot scheduling is still frozen until G2 reconciles the historical work-package plan.
10. Test strategy uses static checks, coverage, accessibility, Playwright E2E/security negatives and Human QoS.
11. Playwright is primary; Selenium is fallback only.
12. Business routes must default to lazy/dynamic loading, with heavy feature-only dependencies split from the startup shell where practical.
