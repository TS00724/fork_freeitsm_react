## Responsibility refactor

The WP-04 compatibility files had multiple distinct responsibilities even though
compact formatting kept physical LOC low:

- `Http.php`: exception + response + request parsing + request context;
- `Router.php`: route definition + response factory + dispatcher + kernel.

They are now compatibility loaders, with responsibilities moved to focused
siblings:

```text
api/ui/v1/lib/
├── UiApiException.php
├── UiApiHttpResponse.php
├── UiApiRequest.php
├── UiApiRequestContext.php
├── UiApiRoute.php
├── UiApiResponseFactory.php
├── UiApiRouter.php
└── UiApiKernel.php
```

This is responsibility-based separation, not mechanical `part1`/`part2` slicing.
The largest proposed PHP file is `UiApiRequest.php` at 213 physical LOC, below
the 250-line review threshold. No LOC exception is used.
