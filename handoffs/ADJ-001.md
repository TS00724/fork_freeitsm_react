## Confidence assessment

Technical confidence that the prepared implementation can reduce the actual
`/ui/` initial-route JavaScript below 510,780 gzip bytes is **high**, but it is
not a measurement.

Reasons:

1. Home, Architecture, 403, Error and 404 modules are explicit route-level
   dynamic imports instead of synchronous Router dependencies.
2. The default Home route no longer imports `EuiCodeBlock`, so its source no
   longer requires the Prism/Refractor code-highlighting path.
3. AppShell remains the synchronous route composition boundary.
4. The bundle analyzer measures the de-duplicated entry/static closure plus the
   default-route lazy/static closure; moving bytes between filenames cannot
   produce a false pass.
5. The final Phase B gate will fail unless the real initial transfer is below
   510,780 and a forward budget derived from the measured result is committed.

## Phase A implementation

### Frontend governance

- `frontend/src/app/router.tsx`: all five foundation pages use `React.lazy()`;
- `frontend/src/pages/HomePage.tsx`: lightweight semantic `<pre><code>` replaces
  the default-route `EuiCodeBlock` usage;
- `frontend/vite.config.ts`: emits a Vite manifest;
- `frontend/scripts/verify-bundle-budget.mjs`: measures entry, synchronous shell,
  default-route and actual initial-transfer raw/gzip closures plus top chunks;
- `frontend/bundle-budget.json`: forward budget intentionally remains unresolved
  until real Phase B evidence;
- `frontend/scripts/verify-source-size.mjs`: dependency-free LOC gate;
- `frontend/source-size-exceptions.json`: empty, versioned exception registry;
- `frontend/tests/App.test.tsx`: observable tests cover all lazy foundation
  routes and theme switching.

### UI-BFF responsibility refactor

The former `Http.php` and `Router.php` mixed multiple responsibilities despite
compact physical formatting. They remain compatibility loaders; focused sibling
modules now contain the implementation:

```text

├── UiApiRequestContext.php

├── UiApiRouter.php

```

The largest proposed PHP file is `UiApiRequest.php` at 213 physical LOC, below
the 250-line review threshold. No source-size exception is used.
