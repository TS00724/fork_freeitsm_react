## Transport architecture

```text
same-origin browser
        |
        v
/api/ui/v1/index.php
        |
        +-- strict request parsing
        +-- request/correlation context
        +-- declarative route table
        +-- versioned response/error envelope
        +-- generic exception containment
        |
        v
actor / tenant / capabilities / locale / timezone
        unresolved until WP-05
```

Success envelope:

```text
{ data, meta: { apiVersion, requestId, correlationId, timestamp } }
```

Error envelope:

```text
{ error: { code, message, details? }, meta: { ... } }
```

The contract defines 400, 401, 403, 404, 405, 409, 415, 422, 429 and 500.
Only transport-level 400/404/405/415/500 behavior is currently reached by
production foundation routes; the remaining semantics are available for later
handlers and tested without pretending server security exists.
